BCV Exchange Rate

Automatically fetch and apply official USD/EUR rates from the Venezuelan Central Bank (BCV) in your Odoo.

Key Features

  • Automatic Rate Update: Fetches the latest USD and EUR rates from BCV and updates Odoo currency rates daily.
  • Scheduled Cron Job: Includes a scheduled action to update rates automatically every minute, or manually if needed.
  • Invoice Integration: Adds the daily_rate field to the invoice form, showing the current exchange rate for the invoice currency. This field is only visible if the invoice currency differs from the company currency.
  • Multi-Company Support: Updates rates per company, ensuring correct values for each environment.
  • Logging and Traceability: Logs every rate update and warns if BCV is unreachable.

Invoice Integration: The daily_rate field is shown on the invoice form and displays the official BCV rate for the selected currency and date. It is only visible if the invoice currency is different from the company currency.

Automated Updates: The module includes a scheduled cron job that updates USD and EUR rates every minute. You can also trigger the update manually if needed.

Currency Rate Management

Currency Rate List: View all currency rates in Odoo, including those updated by the BCV integration.

USD Rate Details: The form view for res.currency.rate shows the current USD rate as updated from BCV.

EUR Rate Details: The form view for res.currency.rate shows the current EUR rate as updated from BCV.
